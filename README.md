# Todo App

Aplikasi Todo sederhana berbasis React Native menggunakan Expo.

## Deskripsi
Aplikasi ini memungkinkan kamu untuk mencatat, menandai selesai, dan menghapus daftar tugas harian (todo list) secara mudah dan cepat. Dirancang dengan antarmuka yang ringkas, responsif, dan modern.

## Fitur Utama
- Menambah todo baru
- Menandai todo selesai/belum selesai
- Menghapus todo
- Notifikasi toast pada aksi (tambah, ubah, hapus)
- Desain ramah pengguna (User Friendly UI)

## Instalasi
1. Pastikan sudah terpasang [Node.js](https://nodejs.org/) dan [Git](https://git-scm.com/)
2. Install Expo CLI secara global (jika belum):

   ```bash
   npm install -g expo-cli
   ```

3. Clone repository:

   ```bash
   git clone <url-repo-anda>
   cd todo-app
   cd todo-app
   ```

4. Install dependencies:

   ```bash
   npm install
   ```

5. Jalankan aplikasi:

   ```bash
   npm start
   ```
   atau
   ```bash
   expo start
   ```

6. Scan QR code menggunakan aplikasi Expo Go di HP atau jalankan di emulator/virtual device.

## Struktur File Penting
- `App.js` : Komponen utama React Native (UI & Logic)
- `index.js` : Entry point aplikasi
- `app.json` : Konfigurasi Expo project
- `assets/`  : Ikon dan gambar
